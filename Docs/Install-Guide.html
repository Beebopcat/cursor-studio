Switching between Animated and Static

Static - 17 crisp .cur pointers.

Animated - the same 17 roles as looping .ani pointers.

In the app, flip the radio button and press Apply Now again. Manually, choose the other scheme in the Scheme drop-down. Each variant is registered as its own scheme (Set Name (Animated) / (Static)).

Sizes & sharpness

Every cursor file contains 32, 48 and 64 px images, so Windows can pick the closest match for your pointer size and display scale instead of stretching one bitmap. To enlarge pointers: Settings → Accessibility → Mouse pointer and touch → Size.

Troubleshooting

Animated pointer does not moveMake sure the slot points to a .ani file. Re-apply the Animated scheme. A few remote-desktop and game-capture tools show static cursors only.
Blurry cursorSet Accessibility → Mouse pointer size to a step that matches your display scale; every file ships 32/48/64 px.
Script blockedUse the .bat launcher (it bypasses the policy for this one run) or run the headless command shown in section A.
Go backPress Restore Windows Default, or in Pointers pick Windows Default from the Scheme list.

Making your own animated pointer? RealWorld Cursor Editor (GIF/strip → .ani with hotspots) and Custom Cursors Studio (Microsoft Store) both work. The generator in CursorSets/Generator shows how these sets are built.
